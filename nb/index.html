SteadyHelm

En bevegelsesmåler og alarm for båt på iPhone. SteadyHelm viser rulling, stamping, rulleperiode, kurs og vibrasjon, tar opp turene dine og kan varsle deg hvis båten får slagside eller ankeret drar.

Slagside-varsel varsler deg hvis båten begynner å krenge og blir liggende med slagside. Det kan bety vanninntrenging, forskjøvet last eller grunnstøting. Vanlig rulling i bølgene utløser det ikke.

Ankervakt varsler deg hvis båten flytter seg lenger fra ankerpunktet enn du tillater. Den oppdager også tyveri.

Alt blir på telefonen din. Ingen konto, ingen server og ingen sporing.
